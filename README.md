# 宮外妊娠治驗（1854 年署記，京都大學 キ/58） / Kyūgai ninshin chiken [Case record of an extrauterine pregnancy]: Transcription Dataset

《宮外妊娠治驗》是相馬醫者鎌田昌琢於1854年署記的一則漢文病例。它記錄一名患者的病程、作者與同藩醫者的會商、患者家屬表達的意願，以及處置後的照護，末附手繪圖。底本為京都大學附屬圖書館富士川文庫キ/58，可供幕末產科史、臨床書寫及醫者與家屬溝通研究逐圖核對。

Dated 1854, Kyūgai ninshin chiken is a Literary Chinese case record by Sōma physician 鎌田昌琢. It documents a patient's illness, a consultation between physicians, the family's stated wishes, and follow-up care, with a hand-drawn figure at the end. The transcription follows Kyoto University Library’s Fujikawa Collection manuscript, shelfmark キ/58, and supports research on obstetric history and the documentation of clinical decisions in late Edo-period Japan.

## V0.2.0

從封題到署記及圖的8幅館方影像，附記第9幅的物理篇界；提供逐欄TXT、JSON和TEI XML，並標示附圖、圖題、圖字的原圖區域。比對獨立原圖讀法後回圖裁定，採用 11 筆訂正，留存疑讀定位。

Includes the eight scans of the titled work and the boundary on scan nine. Text, JSON and TEI XML provide column-level locations, and the figure, title and label are tied to regions on the source image. An independent image reading was compared with the first transcription. Source-image adjudication adopted 11 changes and retained unresolved readings.

## 方法與覆核 / Methods and review

由 AI 依固定館方影像逐欄讀字，保留原字、版面與疑讀。保留字形及欄序，原圖返點與合符、墨筆細注、印識及圖字分層。範圍止於署記與圖，以同冊後續稿另起為界。人類全文雙校、專家審定、同儕審查及準確率量測尚未進行。實際模型識別與使用量未知。此資料公開供比對與引用，處理程式及影像另存。

An AI assistant transcribed the fixed source images column by column, preserving source forms, layout and uncertain readings. Preserves column order and readable source forms. Return marks, connecting marks, glosses, collection marks and diagram labels are represented separately. The signed conclusion and figure delimit the work within the composite manuscript. Human proofreading, expert review, peer review and accuracy measurement are pending. The actual model identifiers and usage are unknown.
